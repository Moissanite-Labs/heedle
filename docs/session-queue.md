# Session queue

Status: `proposed`. Heedle remains an instrument for a checked change to a draft. This note records a neighboring surface. It steers an agent session. It does not steer the next tokens of a generated paragraph, and it does not change the Heedle gate.

A person needs a way to send a steer while a turn is still running. The note waits until the next gap between steps. Stopping the work is a different gesture. Focus shows what the session is doing. A lock is a phrase that stays. A scrub drops the last step.

Those four ideas are the Spaceship IDE set: focus, attention lock, a future vector, and scrub. They are used here as a queue of harness state. https://github.com/chuanqisun/spaceship

The wider claim is that an ancillary model sets which parameters are even open before the heavy model computes. That claim is recorded in Siliconcordat Loom. https://github.com/siliconcordat/loom/blob/main/docs/08-contextual-compute.md
